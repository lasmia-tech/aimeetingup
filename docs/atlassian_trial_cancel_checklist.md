# Atlassian(Confluence) 유료 플랜 체험(Trial) 안전하게 사용하기 — 체크리스트

목적: `Standard` 등 유료 플랜의 무료 체험(Trial)을 시작할 때 카드 등록 후 자동 결제(Trial 종료 후)이 발생하지 않도록 안전하게 처리하는 절차입니다.

요약 결론
- 대부분의 경우 ``Start free trial`` 절차에서 결제수단 입력을 요구할 수 있습니다. 결제가 자동으로 발생하려면 **구독을 취소하지 않거나 취소 후 결제수단을 남겨둔 경우**가 일반적입니다.
- 안전한 방법: 체험 시작 후 즉시 **결제 알림/종료일 확인** → trial 종료 전에 **구독 취소**(Cancel subscription / Cancel trial) 또는 결제수단 삭제 → 시스템에서 청구가 이루어지지 않도록 합니다.

사전 준비
- Confluence 관리 권한(사이트 관리자)이 필요합니다. admin.atlassian.com 접근 권한이 없다면 관리자에게 위 절차를 요청하세요.

실행 단계
1) Trial 시작 전(가입 화면 확인)
   - `https://www.atlassian.com/software/confluence/pricing`에서 `Start free trial` 클릭.
   - 가입/결제 화면에서 "결제수단 필수인지"(Add payment method required) 여부를 확인하세요. 화면에 명시됩니다.

2) 결제수단을 입력해야 하는 경우(입력 전 체크)
   - 카드 입력 후 즉시 청구되지는 않습니다. Trial 기간(예: 14일) 내에는 보통 청구되지 않음.
   - 안전 조치: 카드 입력하더라도 즉시 **구독을 취소**하면(trial 기간 내 취소) 자동 결제가 발생하지 않습니다.

3) Trial 시작 직후(반드시 수행)
   - 관리자 콘솔 접속: `https://admin.atlassian.com` → 해당 사이트 선택 → `Billing` 또는 `Subscriptions`로 이동
   - **Trial end date(체험 종료일)**와 **구독 상태** 확인(화면에 표시됨).
   - 이메일 알림/캘린더 리마인더 설정: 체험 종료일 하루 전/당일에 알림이 오도록 캘린더에 등록하세요.

4) Trial 취소(체험 종료 전에 수행해야 함)
   - `Billing` → 해당 구독(Confluence Standard) → `Cancel subscription` 또는 `Manage trial` → `Cancel trial` 옵션을 선택하세요.
   - 취소가 정상 처리되면 구독 상태가 `Canceled` 또는 `Trial canceled`로 표시됩니다. 스크린샷을 남겨 두세요.

5) 결제수단 제거(필요한 경우)
   - 구독이 활성(또는 결제 대기) 상태가 아니라면 `Billing` → `Payment methods`에서 카드 정보를 삭제할 수 있습니다.
   - 주의: 결제수단을 삭제하면 다음에 다시 구독을 시작할 때 결제정보를 다시 입력해야 합니다.

6) 체험 직후 로그(선택)
   - `Billing`에서 체험 시작/종료일과 인보이스(혹은 예정 인보이스)를 캡처해서 운영문서로 보관하세요.

추가 팁
- 이메일: Atlassian은 체험 종료·결제 예정·청구 성공 등의 이메일을 발송합니다. 발송되는 이메일 주소(사이트 관리자)를 확인하고 수신함을 모니터링하세요.
- 자동화: 체험 시작 시 서버나 개인 캘린더에 종료일 알림을 자동 생성하는 스크립트를 사용하면 편리합니다.
- 환불 정책: 만약 실수로 청구되면 Atlassian 지원을 통해 환불을 요청할 수 있습니다 — 지원 티켓을 빠르게 제출하세요.

문장 템플릿(관리자에게 보낼 메시지)

제목: Confluence Standard 체험 결제 관련 확인 요청

본문:
```
안녕하세요,

Confluence Standard 2주 무료 체험을 시작하려고 합니다. 결제수단 입력이 필요해서 안내 부탁드립니다.

질문:
1) 체험이 끝난 뒤 자동으로 결제가 진행되나요? (체험 종료 시점에 구독을 취소하면 결제되지 않나요?)
2) 체험 시작을 위해 결제 카드를 등록할 경우, 체험 기간 내에 구독을 취소하면 카드로 청구가 발생하지 않나요?
3) 체험 시작 후 구독 취소 및 결제수단 삭제 절차를 해주실 수 있나요? (또는 절차 안내 부탁드립니다)

감사합니다.
```
